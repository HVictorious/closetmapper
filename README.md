# Closet Mapper

Maps network closets: racks, switches, patch panels, ports, cables, fiber, power, rooms and floor plans.

Live at **https://closetmapper.cloud**

The whole app is the single file `index.html`. Accounts, team maps and photos are stored in Supabase (see `supabase/schema.sql`).


## Updating the site
Replace `index.html` with the new version (keep the file name) and commit. GitHub Pages republishes in a minute or two.
